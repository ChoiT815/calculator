##실행 방법                                      
1. 프로젝트 실행                       
2. 콘솔에 출력되는 안내에 따라 값을 입력
- 첫 번째 숫자 : 
- 두 번째 숫자 :
- 사칙연산 기호 :
3. 계산 결과 출력
4. 이후 명령을 선택할 수 있음
- 'exit' = 종료
- 'delete' = 저장된 값들 중 첫 번째 값 삭제
- 'search' = 기준값을 입력해 기준값보다 큰 계산 결과를 조회
---

##주요 기능
###사칙연산
- 덧셈, 뺄셈, 곱셈, 나눗셈
- enum을 활용해 연산타입을 명확하게 구분
- 0으로 나누면 'ArithmeticException' 처리
---

###입력값 검증
- 올바른 연산자가 입력될 때까지 반복 요청
- 잘못된 입력 시 사용자 친화적인 안내 메시지 출력
---

###계산 결과 저장
- 계산된 결과를 내부 컬렉션에 저장
- 이후 삭제 및 조회 기능에서 활용
---

###결과 삭제 기능('delete')
- 가장 먼저 저장된 계산 결과를 삭제
- FIFO(선입선출) 방식으로 관리
---

###결과 조회 기능('search')
- 기준값(threshold)을 입력받음
- 기준값보다 큰 계산 결과 목록 출력
---

##실행 예시
첫 번째 숫자를 입력하세요: 10
두 번째 숫자를 입력하세요: 2
사칙연산 기호를 입력하세요: /
결과: 5.0
더 계산하시겠습니까? (종료:exit, 삭제:delete, 조회:search) : search
기준값을 입력하세요: 3
조회 결과: 5.0
